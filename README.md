# Measure the Pixels site

This repository is the generated static deployment for
[measurethepixels.com](https://measurethepixels.com). Its HTML and image files
are refreshed automatically from the private production pipeline; the public
NOVA source and contributor documentation live in
[`measurethepixels/nova`](https://github.com/measurethepixels/nova).

GitHub Wiki and Projects are intentionally disabled here because this is a
deployment repository, not a documentation or project-management surface.
Public questions and future FAQ content belong in the NOVA repository, while
handbook material will be published through the website when it is ready.
